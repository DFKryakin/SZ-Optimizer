# ⚡ SZ Optimizer v1.5 — Бустер FPS, оптимизация Windows и кастомный прицел для STALZONE (STALCRAFT: X)

Открытый, бесплатный и **100% легальный** оптимизатор Windows 10/11, созданный специально для **STALZONE / STALCRAFT: X**.

## 🛡️ Полная безопасность (Одобрено под античит EXENS)
- **Никакого вмешательства в клиент игры:** программа не читает и не изменяет память процесса, не использует макросы и не вырезает текстуры/свет.
- **Только штатные механизмы Windows:** управление приоритетами CPU/I/O, системным таймером, службами Windows, настройками видеодрайвера, DWM-оверлеем прицела и файлом options.json.
- **Мгновенный откат:** все изменения легко возвращаются в исходное состояние кнопкой **«↺ Откатить всё»** или автоматически при выходе из игры.

## 🚀 Основные возможности v1.5
- **Автоподбор под железо:** анализ процессора (ядра/потоки), объёма ОЗУ и видеокарты в 1 клик.
- **Игровой режим и разгрузка фона:** высокий приоритет для stalzonew.exe, изоляция CPU 0, разгрузка браузеров, Steam/Epic/Overwolf и пауза телеметрии/поиска на время сессии.
- **Аппаратная диагностика и GPU/CPU твики:** отключение парковки ядер, ASPM, принудительная дискретная видеокарта и HAGS, очистка кэша EXBO/%TEMP% и шейдеров.
- **JVM Враппер (6 ГБ → 8–16 ГБ ОЗУ):** безопасная настройка выделения памяти и сборщика мусора Java (G1GC, AlwaysPreTouch, UseStringDeduplication) с использованием официального EXBO JVM Wrapper.
- **Настройки STALZONE (options.json) и выбор региона (RU ↔ EU):** 5 готовых пресетов графики без урезания дальности прорисовки игроков.
- **Кастомный DWM-прицел (0% потерь FPS):** 16+ форм, пиксельный редактор 16×16, палитра HSV, авто-смена профилей под слоты 1–5 и скрытие при зажатии ПКМ.
- **Разрешение 4:3 / 16:10 и кастомные Гц:** быстрое переключение растянутых разрешений с автовозвратом после выхода из игры.
- **6 тем оформления + режим трея:** минимальное потребление ОЗУ в фоне и мгновенные всплывающие подсказки (?) на каждой функции.

## 📥 Как скачать и запустить (Важно про Windows SmartScreen!)
1. Перейдите в раздел **[Releases](https://github.com)** справа и скачайте **SZOptimizer.exe**.
2. При первом запуске Windows SmartScreen может показать синее окно *«Система Windows защитила ваш компьютер»* — это стандартное предупреждение для новых open-source программ без платной цифровой подписи:
   - Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
3. Запускайте от имени Администратора (требуется для управления приоритетами, службами и системным таймером).
