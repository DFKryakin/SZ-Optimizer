# ⚡ SZ Optimizer (STALZONE / STALCRAFT: X Edition)

Открытый и полностью легальный инструмент для оптимизации Windows, снижения задержки ввода (Input Lag) и устранения микрофризов в **STALZONE (STALCRAFT: X)**.

## 🛡️ Безопасность и прозрачность
* **100% Open Source:** Весь исходный код открыт для проверки — программа не лезет в память игры, не меняет файлы клиента и не собирает личные данные.
* **Автоматический бэкап и откат:** Перед запуском создаётся снимок настроек (`backup.json`). При выходе из игры или нажатии кнопки «Откатить всё» Windows возвращается в исходное состояние.
* **Защита от сбоев (Crash Recovery):** Если во время игры отключится свет, при следующем запуске программа сама восстановит системные параметры.

## 🚀 Функции версии v1.0
1. **Очистка кэша шейдеров и ОЗУ (Standby List):** Удаление старых кэшей OpenGL/NVIDIA/AMD перед стартом и сброс закэшированной памяти в фоне.
2. **Оптимизация сети (Nagle Fix):** Отключение задержки отправки мелких пакетов (`TCPNoDelay`) и запрет сна сетевой карты.
3. **Честный ввод мыши 1:1:** Отключение акселерации мыши, залипания клавиш (`5x Shift`) и энергосбережения USB-портов.
4. **Сессионный игровой режим:** Высокий приоритет для `stalzonew.exe` и временная пауза фоновых служб Windows (поиск, телеметрия) на время катки.
5. **Фикс полноэкранного режима:** Отключение оптимизации во весь экран и назначение высокого приоритета GPU.
6. **Ускорение системного таймера (1.0 мс):** Сжатие таймера прерываний Windows на время игровой сессии для ровного фреймтайма.
7. **Планировщик игр Windows (MMCSS):** Выделение максимального приоритета ресурсам игры.
8. **Опциональный подбор DNS:** Проверка пинга до Cloudflare / Google / Яндекс с мгновенным откатом на DHCP.
9. **Очистка логов STALZONE:** Удаление старых логов и дампов крашей без потери настроек игры.
10. **Тихий режим (Трей):** Автоматическое отслеживание запуска и закрытия клиента.

## 📥 Как скачать и запустить
1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте файл **`SZ_Optimizer_v1.0.exe`**.
2. Запустите файл (требуются права Администратора для работы с таймером и службами).
3. Выберите нужные пункты (напротив каждого есть подсказка `[?]`) и нажмите **«Применить выбранное и запустить STALZONE»**.
